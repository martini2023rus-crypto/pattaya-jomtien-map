## Третья страница: предложение LUNVO о совместной точке SenWay

`lunvo/index.html` — страница-предложение партнёру (версия 5, 28.09.2026): сделка «20 % LUNVO
на 6 месяцев до 31.03.2027, деньги в компанию, выход по формуле cash flow × 2,4 в обе стороны,
не ниже цены входа»; совместная работа — две ветки на деньги MaxIn (мобильная точка и массаж
на EV-станции, деление 40/30/30: капитал MaxIn — Инна, работа Max, работа LUNVO) с экономикой
по сценариям; правила и защита, что нужно до сделки, календарь.
Условия точки SenWay под LUNVO — в отдельном термшите, на страницу не выносятся.
Раздел «Как это выглядит» — анимированная схема (inline SVG, подписи по-английски): два бизнеса
со спутниками-точками → ветки → пилот 70/30; кнопки шагов и Play, автозапуск при прокрутке,
примеры месяца по каждой ветке карточками под схемой. Раздел «Экономика веток» — три сценария.

Режим правки для владельца: открыть `…/lunvo/#edit`, кнопка «🔑 Ключ» — вставить fine-grained
токен GitHub (доступ Contents: read/write только к этому репозиторию; хранится в localStorage
браузера владельца), «✎ Править» — текст правится прямо на странице, «Опубликовать» — страница
отправляет свой HTML в `lunvo/index.html` через GitHub Contents API (коммит «lunvo: правка
владельца со страницы»). После этого локальная копия отстаёт: перед своими правками — `git pull`.

Комментарии под разделами: скрипт в конце `lunvo/index.html` добавляет к каждому разделу блок
«💬 Комментарии» с кнопкой «Написать в Telegram» (t.me/share) и, если задан `COMMENTS_URL`,
формой имя + текст. Хранилище — Google-таблица «LUNVO — комментарии к странице» (папка Диска
«1.20 SenWay / 07_Партнёрство_Лунво»), к ней привязан Apps Script (исходник —
`Desktop\Claude\1.20 Senway\07_Партнёрство_Лунво\comments_apps_script.gs`), развёрнутый как
веб-приложение «выполнять от имени владельца, доступ всем». Адрес `/exec` вписывается в
`COMMENTS_URL`. GET — список, POST (text/plain, JSON) — новый комментарий; владельцу уходит письмо.
Режим правки удаляет блоки `.cm` из сохраняемого HTML — они строятся заново при загрузке.
Исходник условий — термшит в `Desktop\Claude\1.20 Senway\07_Партнёрство_Лунво`.
`publish.ps1` её не трогает; обновляется руками: правка файла, `git add lunvo/index.html`, коммит, `git push`.
