## Третья страница: предложение LUNVO о совместной точке SenWay

`lunvo/index.html` — страница-предложение партнёру: пилот 1.10–31.12 — две параллельные ветки
на деньги MaxIn (мобильная точка LUNVO на ярмарках ТЦ и массаж SenWay в боксах на EV-станции,
прибыль 70/30, пять правил отгораживания от долгов LUNVO) плюс обмен временем команд; вопрос 1 «SenWay входит в LUNVO»
(вклады, что просим, формула цены), вопрос 2 «Максим входит в SenWay» (доля за результат),
правила для обоих вопросов, выходы при плохих сценариях, что нужно до решений, календарь.
Условия точки SenWay под LUNVO — в отдельном термшите, на страницу не выносятся.
Раздел «Как это выглядит» — анимированная схема (inline SVG, подписи по-английски): два бизнеса
со спутниками-точками → ветки → пилот 70/30; кнопки шагов и Play, автозапуск при прокрутке,
примеры месяца по каждой ветке карточками под схемой. Раздел «Экономика веток» — три сценария.

Режим правки для владельца: открыть `…/lunvo/#edit`, кнопка «🔑 Ключ» — вставить fine-grained
токен GitHub (доступ Contents: read/write только к этому репозиторию; хранится в localStorage
браузера владельца), «✎ Править» — текст правится прямо на странице, «Опубликовать» — страница
отправляет свой HTML в `lunvo/index.html` через GitHub Contents API (коммит «lunvo: правка
владельца со страницы»). После этого локальная копия отстаёт: перед своими правками — `git pull`.
